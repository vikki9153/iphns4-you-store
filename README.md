# Iphns4 You Mobile Store

A responsive storefront for Iphns4 You in Sasaram, Bihar. The site showcases new and pre-owned phones, buy/sell/exchange services, store details, and WhatsApp ordering.

## Preview locally

Open `index.html` in a browser. The catalog is data-driven; add verified current listings to the `product-data` JSON block in `index.html` with a model, storage, condition, price, and optional image path.
